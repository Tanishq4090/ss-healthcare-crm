# Final Product Scope — SS Healthcare CRM

## In Scope

- Admin-only CRM system
- SS Healthcare logo and current green/blue theme
- HealthCare/SS Health Care-style admin module structure
- Callyzer manual-call review integration
- Manual Add to Pipeline workflow
- Optional Supabase recording upload
- CRM pipeline
- Clients
- AI HR / employee directory
- Manual attendance
- Finance/Billing placeholder module
- Access Control

## Out of Scope

- Public website
- AI agent calling
- SS Health Care Callyzer Calls outbound/inbound calling
- Auto-adding every call directly to pipeline
- Storing every recording automatically
- Fully automated transcription guarantee before real audio validation

## Core Operating Principle

All calls are logged, but only qualified inquiries become CRM leads.

This avoids pipeline pollution from wrong numbers, spam calls, incomplete inquiries, and repeat calls.
